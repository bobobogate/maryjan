安靜・獨處・相遇

相逢寧靜中

離開片刻的忙碌，回到獨處的心靈花園，讓焦慮的身心停泊下來。

你是否曾有過這樣的經驗：生活很忙、很累，卻仍然停不下來？我們像被追趕一般，不停工作、安排活動，漸漸只顧著滿足別人的期待，卻失去與自己的連結，也感覺與主愈來愈遠。

獨處的心靈花園

在充滿聲音與訊息的世界裡，我們很難聽見自己的想法，更不容易安靜地留意主。當我們暫時離開人群與社群媒體，回到獨處的空間，焦慮的身心才有機會慢慢停泊。

獨處並不等於孤單。它是一個機會，使我們與真實的自己相遇，也與主相遇。從忙碌生活中暫停，覺察此刻的情緒與感受，本身就是一種溫柔的自我照顧。

我們有時害怕安靜，因為一停下來，就可能看見自己的脆弱、空虛與真正的渴望。於是，我們用更多工作、頭銜和成就包圍自己。然而，惟有帶著真實的自己來到主面前，關係才可能變得深刻而自由。

給自己一個練習：今天找一處安靜的地方，放下手機十分鐘。先感受呼吸，再問自己：「我現在真正的感受是什麼？我渴望主如何陪伴我？」不急著得到答案，只是安靜地停留。

召命・藝術・宣教

從畫筆到陪伴

藝術曾是一個想要完成的夢，後來成為回應召命、陪伴生命的路。

我從小喜歡畫畫，十八歲舉辦第一次畫展，也曾盼望出國深造，成為專業藝術家。二十歲信主之後，生命的方向逐漸改變。1984 年，我投入校園團契全職服事，把許多時間放在青少年輔導與生命陪伴中。

那些年，我看見許多青少年承受家庭破碎與成長的孤單。自己的生命經驗，使我更願意靠近他們。藝術暫時退到生活的後方，卻沒有真正離開；它像一顆種子，在不同階段等待再次發芽。

故事與圖像重新回來

2000 年，我開始創作繪本，記錄孩子的成長，也透過故事與圖像分享信仰。後來在牧會、社區工作與海外服事中，我一次次發現：藝術能越過語言的界線，觸碰人不容易說出口的內在。

2019 年到英國與德國分享心靈繪本之後，我進一步學習藝術治療、諮商輔導與依納爵靈修。長時間的安靜禱告，使我更確定要整合藝術、靈性引導與心理陪伴，幫助人與自己建立連結，也與主建立更真實的關係。

回頭看，神並沒有拿走我的畫筆，而是重新把它交還給我。藝術不再只是追求技巧或成就，而成為服事、陪伴與宣教的禮物。每一次創作，每一場工作坊，都邀請我們在色彩與安靜中，走近自己的心，也走近那位一直同行的主。

藝術靈修・心靈陪伴

藝術是超越語言的力量

當言語還沒有準備好，線條、色彩與圖像可以先替心說話。

藝術靈修不要求畫得像，也不以作品美不美來衡量。它關心的是：當我拿起畫筆時，心裡有什麼正在發生？色彩、形狀與動作，往往能讓被壓抑的情緒得到出口，也讓我們看見自己真正的需要。

從安頓開始

每一次帶領，我會先邀請學員藉著呼吸、身體覺察與安靜禱告，從忙碌緊張的生活回到此刻。當心慢下來，雙手就能更自由地創作，內在細微的感受也比較容易被聽見。

創作之後，我們在安全、尊重與保密的團體中觀看作品。分享不是分析別人的圖，也不急著給建議，而是說出自己的感受，聆聽創作者的故事。這樣的陪伴，使人感到被看見，也讓團體逐漸建立信任。

在畫中與主對話

藝術也能成為祈禱。有人在黑夜與漂泊的圖像中看見引領，有人在用力塗畫時承認多年壓住的憤怒，也有人在自然默觀與創作中重新發現盼望。圖像沒有替生命提供快速答案，卻為我們打開一處可以誠實停留的空間。

藝術的力量，在於它容許我們以完整的自己來到主面前。悲傷、喜樂、渴望、困惑，都可以成為祈禱。當我們不再要求自己表現得完美，反而更可能在真實之中，經驗上帝的同在與愛。
